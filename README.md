# Java Quiz Application

A **Java Swing-based Quiz Application** that dynamically loads questions from an **SQLite database**.  
This project is developed as part of the **Java Training Program** for IP University students.

---

## Features

- Collects **student information** at the start (Name, Enrollment No., Course)  
- Loads **questions from SQLite database** dynamically  
- Multiple choice questions with **Next** and **Back** navigation  
- Tracks **user-selected answers**  
- Calculates and displays **score at the end**  
- User-friendly **GUI interface**  

---
